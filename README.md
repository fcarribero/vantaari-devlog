# Vantaari Devlog

Devlog site for Vantaari, a sandbox space game. Built with [Astro](https://astro.build), bilingual (Spanish default, English under `/en/`).

Live at https://fcarribero.github.io/vantaari-devlog/

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
